# Live Task

The purpose of the live task is to extend the API specification and its corresponding implementation. You will add a new admin feature to let administrators know how many times a keyword was searched for by users (from the moment the server is started). Your design decisions and validation of the implementation should be justified in the Report.

### To do

- [ ] Add the new feature in the [`api_specification.yaml`](src/main/resources/api_specification.yaml) file.
- [ ] Explain your design decisions at the end of the [`Report.md`](Report.md) file.
- [ ] Implement the new feature in your [`SearchEngineServer.java`](src/main/java/searchengine/SearchEngineServer.java) . Verifies that it works as intended according both according to the provided instructions and according to the written API specification. Explain your experiments and validation in [`Report.md`](Report.md).
- [ ] Update your project, and make a new **commit and push**.

### Grading

The new admin feature is properly defined in the [`api_specification.yaml`](src/main/resources/api_specification.yaml). Its definition is well justified in [`Report.md`](Report.md). The [`SearchEngineServer.java`](src/main/java/searchengine/SearchEngineServer.java) implements the feature properly and the validation of the implementation is present in the [`Report.md`](Report.md) file.
