# The Anatomy of a Search Engine

The repository contains a gradle applications project template for completing Assignment 2.

## Project Structure

```bash
src
└── main
│    ├── java
          ├── searchengine
                    ├──  IndexInverter.java #Implementation of a class with a method to create the inverted index from the index. This class does not need to be modified.
│    │              └── MultithreadedCrawler.java #Instantiation of a multithreaded crawler. This class needs to be completed for task 2.
│    │              └── SearchEngineServer.java #Implementation of a search engine. This class needs to be completed for task 4.
                    └── Searcher.java #Implementation of a class with a method to search the URLs corresponding to a keyword using the inverted index. This class does not need to be modified.
│    │              └── SimpleCrawler.java #Instantiation of a simple crawler (with only one thread). This class needs to be completed for task 1.
│    ├──  resources
│         ├──  index.csv  # CSV file to store the index generated by the crawler.
│         └── inverted_index.csv  # CSV file to store the inverted index generated by the index inverter.
│         └── api_specification.yaml  # OpenAPI specification of the Search Engine. To complete for task 3.
└── test
      ├── IndexInverterTest.java 
      ├── SearchEngineServerTest.java
      └── SearcherTest.java 

├── build.gradle # A file used by Gradle to indicate how to build the project. It also includes predefined tasks to run.
├── gradlew # A file used by Gradle on Linux/Mac computers.
├── gradlew.bat # A file used by Gradle on Windows computers.
├── README.md # This file, with the link to the instructions
├── TASKS.md # The file with the instructions
├── SETUP.md # A file with the setup instructions.
├── Report.md # The Report, to complete and send back
└── settings.gradle # A file used by Gradle
```

The instructions are provided in [`TASKS.md`](TASKS.md).
